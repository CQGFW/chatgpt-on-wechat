## 🤝 多 Agent 团队

CowAgent 不再局限于单个 Agent。现在可以创建多个 Agent 组成团队，各自拥有独立的职责、模型、技能和知识，既能单独工作，也能在同一会话中协作完成复杂任务。Web 控制台与桌面客户端均已支持：

- **团队管理**：以独立的「智能体团队」页面创建和维护 Agent，配置名称、头像、职责与默认模型，并可从已有 Agent 复制配置作为起点。
- **群聊协作**：在一个会话中加入多个 Agent，通过 `@` 指定成员应答；每个 Agent 使用各自配置的模型，气泡上标注发言者。
- **委派机制**：群聊设有主 Agent（负责人），可将不属于自己领域的任务转交给更合适的成员，支持多跳委派并受范围、深度与时长约束。
- **资源隔离**：每个 Agent 拥有独立的工作空间、记忆与会话；知识库可在共享与独立之间切换，切回共享时独立库内容予以保留。
- **通道多实例**：同一种通道可运行多个实例，分别绑定不同的 Agent 或团队，对外呈现为各自独立的助手；绑定改动即时生效，无需重启。支持微信、企业微信机器人、钉钉、飞书、QQ、Telegram、Slack、Discord 等。
- **分 Agent 视图**：知识、记忆、定时任务页面均按所属 Agent 区分展示，任务列表带负责人标签。

Thanks @AaronZ345 (#2975, #2973)、@zkjqd (#3096)、@cowagent (#3118)

## ⏰ 定时任务升级

定时任务全面重构，投递更可靠、配置更清晰，并适配多 Agent 场景：

- **跨通道接收人**：任务可投递到预先配置的可信接收人，不再局限于创建任务时所在的通道。Thanks @dajiaohuang (#3043)
- **重设计的任务弹窗**：改为「通道实例 → 接收人」两步选择，支持实例改名、接收人刷新，并根据实例绑定展示负责人；Web 与桌面客户端一致。
- **投递可靠性**：投递改为路由到运行中的通道实例，修复多 Agent 场景下微信任务重启后一直「未就绪」的问题（#3120）；投递失败时改为报错重试，避免一次性任务被误判为已送达而丢失。
- **统一任务存储**：各 Agent 的任务合并为单一全局存储，任务归属依据其投递实例的绑定实时推导，重新绑定通道即可迁移任务，无需改写。

## 📊 上下文用量可视化

对话上下文的占用现在可视、可控，长对话不再因超出窗口而中断：

- **用量指示器**：清除上下文按钮上以环形图展示当前上下文占用，可查看构成明细。
- **自动压缩**：占用接近上限时自动压缩历史，也可在需要时手动触发同步压缩。
- **按模型推算预算**：上下文预算依据所选模型自动推导，`agent_max_context_tokens` 作为可选的成本上限。

Thanks @chimyves (#3087)、@sufan721 (#3079)

## 🤖 模型能力

- **新增模型**：接入 `claude-fable-5-1`、`qwen3.8-flash`、`glm-5.3-flash`，以及视觉模型 `deepseek-v4-flash-vision-exp`（Thanks @a1094174619 #3094）。
- **模型故障回退**：可配置备用模型，当主模型整轮失败（密钥失效、服务不可用等）时自动切换，避免因单一厂商故障而中断。Thanks @alanyz106 (#3099)
- **新增搜索厂商**：联网搜索接入 AnySearch（Thanks @WangPan59 #3083）、Serply（Thanks @googio #3071）与 Parallel Search（Thanks @georgeatparallel #3116）。

## 🛠 优化与修复

- **记忆分块**：Markdown 记忆与知识文档按标题分块，并在分块版本过期时提示重建。Thanks @alanyz106 (#3115)
- **备份恢复**：备份纳入全部 Agent 工作空间，修正多 Agent 场景下的嵌套归档、恢复布局与版本兼容。
- **定时任务**：修复并发更新任务丢失的问题（Thanks @Whxuan0701 #3062）。
- **技能修复**：加固 tar 归档解压（Thanks @Whxuan0701 #3063）；安装技能时解析仓库默认分支而非默认使用 `main`（Thanks @aniruddhaadak80 #3080）；`/skill list` 按 Agent 区分并清理未安装技能。
- **MCP 增强**：支持工具名前缀（Thanks @georgeatparallel #3116）；恢复过期的 Streamable HTTP 会话（Thanks @yiheng-kkk ad1f686）；多个 Agent 共用同一 `mcp.json` 时复用子进程、去除重复加载日志。
- **子 Agent 修复**：修复子 Agent 会清空父级会话回退设置的问题（Thanks @alanyz106 #3111）。
- **图像生成**：修复 ModelScope `IMAGE_CREATE` 因参数不匹配而报错的问题（Thanks @Anai-Guo #3097）。
- **中断识别**：向 Agent 循环透传 `stop_reason`，以区分模型主动结束与被输出上限截断（Thanks @6vision #3074）。
- **附件识别**：按解析后的路径判断关键词附件 URL（Thanks @Whxuan0701 #3061）。
- **网关归属**：为 OrcaRouter 网关请求补充来源归属（Thanks @Marc-oss-hub #3058）。
- **代理渲染**：为 `/chat` 设置 Content-Type，使控制台在带 nosniff 的反向代理后正常渲染（Thanks @alanyz106 #3110）。
- **头像处理**：修复上传头像因按文本解码而失败的问题，改为读取原始字节（Thanks @mengluo04）。
- **钉钉通道**：流式连接禁用代理并对重连做退避，消除持续报错。
- **Windows 客户端**：修复更新安装破坏快捷方式的问题。
- **评估工具**：新增最小化的 Agent 轨迹评估流程。Thanks @yanzhiliaoliao (#3100)
- **文档**：日语文档语言切换器补充繁体中文入口（Thanks @c020627 #3072）；补充 Kimi 相关链接（Thanks @oriengy #2885）。
